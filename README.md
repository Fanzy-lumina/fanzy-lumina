# Fanzy Lumina — Website Profil Perusahaan

Website statis satu halaman dengan desain responsif untuk desktop dan ponsel.

## Isi folder
- `index.html` — struktur dan konten halaman.
- `css/style.css` — desain dan layout responsif.
- `js/script.js` — menu mobile, tahun otomatis, dan form demo email.

## Cara melihat di komputer
1. Ekstrak file ZIP.
2. Buka folder `fanzy-lumina`.
3. Klik dua kali `index.html` untuk membukanya di browser.

Website menggunakan Google Fonts, Lucide Icons, dan gambar dari Unsplash sehingga fitur tersebut membutuhkan koneksi internet.

## Sebelum diterbitkan
1. Ganti alamat `halo@fanzylumina.example` pada `index.html` dan `js/script.js` dengan alamat email bisnis yang benar.
2. Ganti testimoni contoh dengan ulasan nyata atau hapus bagian tersebut.
3. Pastikan nama layanan/produk, alamat, dan klaim perusahaan sesuai kenyataan.
4. Ubah judul, teks, dan gambar jika diperlukan.

Form kontak saat ini adalah demo berbasis `mailto:`. Form ini tidak menyimpan atau mengirim data ke server. Untuk formulir online sungguhan, hubungkan ke layanan formulir atau backend yang tepercaya.

## Publikasikan gratis dengan GitHub Pages
1. Buat/login akun di https://github.com/
2. Buat repository baru bernama `fanzy-lumina`.
3. Unggah `index.html`, folder `css`, folder `js`, dan file lain yang diperlukan dari folder ini ke root repository (jangan unggah ZIP saja).
4. Buka **Settings → Pages** di repository.
5. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
7. Tunggu proses deployment selesai. GitHub akan menampilkan alamat website pada halaman Pages.

Alamat biasanya berbentuk:
`https://USERNAME.github.io/fanzy-lumina/`

Ganti `USERNAME` dengan nama akun GitHub kamu. Alamat tersebut hanyalah pola contoh; website belum online sampai repository dibuat dan Pages diaktifkan.

## Domain khusus (opsional)
Kamu bisa membeli domain sendiri, lalu hubungkan melalui pengaturan GitHub Pages → Custom domain dan ikuti petunjuk DNS yang ditampilkan GitHub. Domain khusus biasanya berbayar.
